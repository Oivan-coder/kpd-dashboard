# КПД лабораторного оборудования

Веб-система для верификации парка анализаторов и расчёта КПД ЦКДЛ Московской области.

## Что уже реализовано

- чтение 8 вкладок ЦКДЛ из Google Sheets;
- чтение сводного листа «Расчет КПД»;
- единый реестр оборудования;
- статусы «проверено / требует уточнения / ошибка / не участвует в КПД»;
- фильтры по ЦКДЛ, уровню, направлению, производителю и статусу;
- отдельная выдача спорных позиций;
- серверное подключение к Google Sheets без публикации ключей в браузере.

## Методика

КПД рассчитывается по целевому контуру. Исключаются 1 уровень/экспресс, микробиология, ПЦР, ИФА, СОЭ и HbA1c, а также неработающее/законсервированное оборудование.

Для модульных систем используется подтвержденная конфигурация. Для Sysmex XN-9000 аналитические модули учитываются отдельно от SP-модуля.

## Настройка Google Sheets

Создайте service account в Google Cloud, включите Google Sheets API и дайте его email доступ на чтение рабочей таблицы.

Переменные окружения:

```
GOOGLE_SHEETS_SPREADSHEET_ID=1NzTRhs4UKyzW_fBBE_THU_ULNSKPZkGnkPrPou2WqNU
GOOGLE_SERVICE_ACCOUNT_EMAIL=...
GOOGLE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n"
```

Без переменных окружения приложение запускается в fallback-режиме на текущем контрольном наборе данных.
