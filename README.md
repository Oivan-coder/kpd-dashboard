# КПД лабораторного оборудования

Веб-система для верификации парка анализаторов и расчёта КПД ЦКДЛ Московской области.

## Концепция

- единый реестр оборудования;
- нормализованный справочник производителей и моделей;
- расчёт мощности по подтверждённой конфигурации;
- статусы: проверено / требует уточнения / ошибка / не участвует в КПД;
- детализация: ЦКДЛ → направление → модель → анализатор;
- Google Sheets как источник/реестр данных;
- история изменений и подтверждение данных ЦКДЛ.

## Методика

Расчёт КПД выполняется только по оборудованию, включённому в целевой контур. Исключаемые направления и оборудование задаются централизованно в справочнике и не редактируются ЦКДЛ.

Для модульных систем мощность рассчитывается по фактической конфигурации. Например, для Sysmex XN-9000 аналитические модули учитываются отдельно от SP-модуля.

## Стек

Next.js + TypeScript. Интеграция с Google Sheets будет подключена через серверный слой, без публикации учётных данных в репозитории.

## Запуск

```bash
npm install
npm run dev
```
